# Votu — assets de email

Imagens hospedadas para as campanhas de email marketing do **Voturuna Life Park**.
O Sender.net, no modo Custom HTML, não hospeda imagem — então as peças apontam para cá.

## Estrutura

- `_marca/` — assets fixos (assinatura), reaproveitados em todo disparo
- `AAAA-MM-DD-nome/` — assets específicos de cada disparo

## Como usar

URL de qualquer arquivo:

```
https://raw.githubusercontent.com/mendesgabriell/votu-email-assets/main/<caminho>
```

Fonte das peças: Google Drive → `08_Comunicação & Conteúdo/02_Voturuna/04_Conteúdo/03_Email/01_Disparos/`
